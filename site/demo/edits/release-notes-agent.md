## Fixes since 0.3

- Feeds that send no `Last-Modified` header are no longer downloaded twice (#212).
- Titles with emoji or right-to-left text no longer break the article list (#218).
- A feed that redirects to HTTPS keeps its read history (#224).
- Marking a whole folder as read now takes one click, not one per feed (#231).
