This page shows you how to change how Penmoss looks: light or dark, the theme, the fonts and the width of your notes.

All of it is in **Settings → Appearance** (**Appearance and Themes** in the command palette). It is kept in your [Primary Notebook](/docs/organise/#the-primary-notebook), so your other devices get it too.

## Light and dark

**Mode** is **Light**, **Dark** or **System**, which follows your Mac's or phone's appearance (the default). **Toggle Dark Mode** switches between light and dark from the command palette.

## Themes

Penmoss comes with eight themes, each in a light and a dark version: **Penmoss** (the default), **Paper**, **Slate**, **Nord**, **Solarized**, **Gruvbox**, **Rosé Pine** and **High Contrast**. Pick one in the grid, or use **Switch Theme…** from the command palette.

### Your own theme

The built-in themes cannot be changed, but you can copy one and change the copy:

1. Choose a theme and **Duplicate** it. The copy is named "… copy" and chosen.
2. Change its name, its light and dark colours, and under **Type and layout** its interface, note and code fonts and its note width (32 to 72 rem).
3. Changes save as you make them.

If a pair of colours is too close for comfortable reading (below WCAG AA contrast), the editor says which. **Delete This Theme** deletes it on every device.

## Fonts

Under **Fonts**:

- **Interface Font** and **Note Font**: Theme Default, System, Serif, Rounded, Humanist, Monospace, or **Custom…** with the name of a font installed on the device. A font that is not installed falls back to the system font.
- **Note Font Size**: 12 to 28 px, 16 by default. **Reset** puts it back.

## Note width

**Note width** is the theme's width, about 52 rem, or **Full Window Width**. **Toggle Full-Width Notes** (⌘⌥⇧W, or the button at the note's top right) switches between them.

## On the Mac

**Settings → Appearance → Compact Title Bar** (on by default) puts the window's buttons in Penmoss's own top row, so notes start higher. Turn it off for macOS's own title bar; Penmoss asks, then reopens its windows where they were. See [The Mac app](/docs/install/mac/#the-compact-title-bar).
