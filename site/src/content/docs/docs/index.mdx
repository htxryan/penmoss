## How Penmoss fits together

Penmoss is an app on your Mac and your Android phone. Each notebook is a private git repository you choose, and the apps sync through it. Your agents reach the same notebooks through the local MCP server or the `penmoss` CLI. There is no Penmoss server and no account.
