These pages show you how to install Penmoss, keep your notes in it, and let your AI agents read and write them.

Penmoss is a free, open source notes app for Mac and Android. Your notes are markdown files in a git repository you choose, and AI agents such as Claude Code can read and edit them through a local MCP server or the `penmoss` CLI. There is no Penmoss server, no account and no subscription.

These pages describe the latest stable release. Anything that is only in the Alpha channel says so.
